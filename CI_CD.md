System process and configuration of product organization for repository, hosting, and deployment:  

The process and configuration for product organization will be using GitHub repositories for the static site, API, and ACP. It will be hosted on Microsoft Azure as a static web application. The deployment process will consist of pushing changes to the repository from a local machine, which will automatically update the static Azure site with every new commit.  
  
The individual developer process (new team member) process and configuration:  

The individual developer process will be pretty straightforward since with full access to the repositories, any new team member will be able to create and test any changes on their local machine, and with the approval of the entire group, can push changes into the production environment by committing changes to the repository.  

The new customer (user) process and configuration:  

The user process and configuration will come down to making it clear that the ECAMS billboard can be used in the hallway in a public setting, and hopefully with a QR code or something similar, feedback can be given. The process more or less hinges on seeing what the product can deliver in a real-world setting.
